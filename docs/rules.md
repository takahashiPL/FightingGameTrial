## 1. 操作

| 入力 | 動作 |
|---|---|
| A | 地上パンチ / 空中パンチ |
| B | 地上キック / 空中キック |
| X | 垂直ジャンプ |
| X + 前 | 前ジャンプ |
| X + 後ろ | 後ろジャンプ |
| 下 | しゃがみ |
| 後ろ | 立ちガード |
| 下 + 後ろ | しゃがみガード |

前後は画面固定ではなく相手との位置関係で決める。

## 2. ジャンプ

- 垂直・前・後ろの3種類
- X入力受理時点の方向で種類を確定
- 着地まで軌道変更なし
- 空中Pushboxは無効
- 空中ガードは不可
- 1ジャンプ中に空中パンチまたは空中キックを1回だけ使用可能

## 3. 通常技

### 立ちパンチ
- 立ち相手に当たる
- しゃがみ相手にはHitboxが届かず Miss
- 通常ヒットは HitStun
- 立ちガード可能
- **初期実装の検証対象技**

### 立ちキック
- 立ち・しゃがみ双方に当たる
- 立ちガード・しゃがみガード可能
- ジャンプ中の相手には原則届かない
- 通常ヒットは Knockdown
- 初期実装対象外（planned）

### しゃがみパンチ
- 低姿勢の近距離攻撃
- 通常ヒットは短い HitStun
- ダウンなし
- 初期実装対象外（planned）

### しゃがみキック
- 低姿勢の迎撃・攻撃相殺向け
- 相手本体へ当たった場合は短い HitStun
- ダウンなし
- 主目的は相手の攻撃Hitboxと接触して Clash を起こすこと
- 初期実装対象外（planned）

### 空中パンチ
- 全ジャンプ種類から使用可能
- 1ジャンプ中1回
- **地上側のガード可否は未確定**（仮に確定しない）
- ダウンなし
- 初期実装対象外（planned）

### 空中キック
- 全ジャンプ種類から使用可能
- 1ジャンプ中1回
- 地上側は立ちガード・しゃがみガード可能
- 通常ヒットは着地ダウン
- 通常ガード時は強めの押し戻し
- 初期実装対象外（planned）

## 4. ガード

攻撃が接触するゲームフレームで、地上側が相手から離れる方向を入力していれば成立する。

- 後ろ: 立ちガード
- 下 + 後ろ: しゃがみガード
- ジャンプ中: ガード不可
- 一度ガードした AttackInstanceId + HitGroupId は、そのActive中に再ヒットしない
- 通常ガード時はダメージなし
- 防御側は BlockStun と GuardPushback
- 攻撃側は Recovery と軽い AttackerRecoil

初期実装では Guard 解決まで必須としない（StandPunch の Hit / Miss 観察を優先してよい）。

## 5. ジャストガード

通常ガード条件を満たし、接触フレームを含む直前3ゲームフレーム以内に後ろ入力を開始していれば成立する。

- 防御側: ダメージなし、短い硬直、押し戻し軽減
- 地上攻撃側: 攻撃中断 → Deflected → Stagger → Neutral
- 空中攻撃側: Hitbox消去 → AirDeflected → 後方へ反発 → 着地 → LandingStagger
- 同じ攻撃は再判定しない

`just_guard_window_frames = 3` は仮値。初期実装対象外でもよい。

## 6. Clash（攻撃相殺）

同一ゲームフレーム内で双方の有効Hitboxが接触した場合、Hurtbox判定より先に Clash を解決する。

- 双方のHitboxを無効化
- 双方ダメージなし
- 双方の攻撃を中断
- 双方を少し後退
- 双方が短い ClashRecoil
- その後 Neutral
- 初期版では全通常技を同格として扱う
- Hitbox同士が接触しただけで、相打ちダメージにはしない

Clash成立フレームでは、そのHitboxによるHurtboxヒットを無効とする。

初期実装対象外（planned）。

## 7. 同一攻撃の多重ヒット防止

攻撃開始ごとに `AttackInstanceId` を発行する。

判定キー:
- AttackInstanceId
- HitGroupId
- AttackerId
- TargetId

一度 Hit / Guard / JustGuard / Clash で処理された組み合わせは再処理しない。

多段技は初期版では未実装。将来は HitGroupId を分ける。

## 8. ダウン・起き上がり

- 地上キック、空中キックなどで Knockdown
- ダウン追撃なし
- KnockdownStart から WakeUp終了まで無敵
- WakeUp終了と Neutral復帰を同時にする
- Neutral復帰時に無敵解除・操作復帰
- 起き上がり時にPushboxが重なっていれば解消
- 壁際では壁側を押し込まず、相手側を外へ移動

初期実装対象外（planned）。

## 9. 壁際

通常ガードで防御側が予定量後退できない場合、未消化分を攻撃側の反動へ加える。

- 中央: 防御側後退 + 攻撃側小反動
- 壁際: 防御側の未消化後退を攻撃側へ転送
- 空中キックを壁際でガード: 攻撃側を空中で後方へ反発
- 壁際ジャストガード: 攻撃側を大きく弾き、仕切り直せる距離を作る
- 壁際Clash: 双方反動。ただし壁側の未消化分は相手側へ一部転送可能

初期実装対象外（planned）。

## 10. 固定ゲームフレーム

内部シミュレーションは60Hz固定。

- 描画FPSとは分離
- 入力は押下・解放・保持をゲームフレーム番号付きで保存
- X + 方向は、X押下フレームと直前2ゲームフレームの方向を参照
- デバッグ停止中は `SimulateOneGameFrame()` を1回だけ実行
- HitStop中も入力は記録するが、アクションフレーム・移動・判定は停止

**初期実装の中核。**
